💾 Backup y restauración de datos
Snapshots locales

La app guarda una copia automática en este dispositivo cada vez que cerrás la pestaña, minimizás o cambiás de ventana (hasta 10, se van rotando). El botón "🚪 Salir" de la barra superior fuerza un snapshot manual antes de cerrar.

Carpeta local

Vinculá una carpeta de tu PC (por ejemplo, tu carpeta de OneDrive o Google Drive sincronizada) y la app va a mantener ahí un archivo riego_backup_<fecha>.json actualizado cada vez que se guarda un cambio — sin tocar nada manualmente. Se conservan los últimos 7 backups por fecha. Requiere Chrome o Brave.

➖ No vinculada
Google Drive

Conectá tu cuenta de Google y la app va a mantener sola un backup actualizado en una carpeta RiegoAdaptativo de tu Drive (archivo backup_autosync.json), sincronizando en segundo plano cada vez que hay cambios. También podés subir una copia con fecha a mano, o restaurar cualquier backup guardado ahí.

➖ Drive: sin conectar
Exportar datos

Descarga todos los datos en un archivo JSON, para guardar a mano donde quieras.

Importar / restaurar

Carga un archivo de backup previamente exportado. Atención: reemplaza todos los datos actuales.

Importar registro de mantenimiento

Importar un registro completado desde la app móvil. Se adosa automáticamente a la ficha del cliente.

Borrar todo excepto logística

Borra clientes, presupuestos, movimientos de fondos, fabricación, instalaciones y finanzas. Preserva todo el catálogo, stock, proveedores, OC, movimientos de stock, kits y configuración.

Reiniciar datos operativos

Borra clientes, presupuestos, movimientos de stock, órdenes de compra, fabricación, instalaciones y finanzas. Preserva catálogo, proveedores, configuración, kits y versiones SW.

Borrar todos los datos

Elimina todos los clientes, dispositivos, historial y configuración. Esta acción no se puede deshacer. Recomendamos exportar un backup antes.

📲 Instalación como PWA

Para instalar esta app en tu dispositivo como si fuera una aplicación nativa, el sistema debe estar publicado en un servidor web (no como archivo local). Opciones recomendadas:

GitHub Pages
Gratis. Subís el archivo a GitHub y queda publicado en una URL fija.
Netlify
Gratis. Arrastrás la carpeta al sitio y obtenés URL en segundos.
Servidor local
XAMPP o Node.js en tu PC. La URL sería localhost.

Los archivos manifest.json y sw.js ya están preparados en el código. Solo necesitás publicar.
